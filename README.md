# Nobella — Luxury Real Estate Experience

Nobella is a modern real estate website built with React and Vite for browsing luxury homes, investment properties, and premium rental opportunities. The experience is designed to feel elegant, high-end, and conversion-focused, with smooth navigation across buying, renting, selling, and property discovery.

## Overview

This project showcases a polished property marketplace experience with:

- premium landing pages and hero storytelling
- property listing cards with rich details
- category pages for buy, rent, and sell
- property detail pages
- wishlist and authentication interactions
- responsive layout for desktop and mobile browsing

## Features

- Luxury-focused homepage with featured listings and trust indicators
- Search and browsing experience across residential and investment properties
- Property detail views with key highlights and CTAs
- Buy, Rent, and Sell sections for different user journeys
- Wishlist drawer for saving favorite homes
- Auth modal for sign-in / sign-up flow
- Responsive layout and premium design system
- Clean routing with React Router

## Tech Stack

- React 19
- Vite
- React Router
- Tailwind CSS
- Lucide React icons
- ESLint for code quality

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the local URL shown in the terminal (typically `http://localhost:5173`).

## Production Build

To generate a production build:

```bash
npm run build
```

Then preview it locally:

```bash
npm run preview
```

## Linting

```bash
npm run lint
```
